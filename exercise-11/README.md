# Exercise 11: Temporary file lifecycle

    ## Aim
    Create and track a temporary file, then remove it in a later commit.

    ## Commands / run instructions
    ```bash
    git add temporary.txt && git commit -m "Add temporary file"
git rm temporary.txt && git commit -m "Remove temporary file"
    ```

    ## Sample output / expected result
    Expected result: history shows the file being added and later removed.
