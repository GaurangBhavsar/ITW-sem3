# Exercise 03: Greeting script

    ## Aim
    Ask the user for a name and print a greeting. Reject empty input.

    ## Commands / run instructions
    ```bash
    bash greet.sh
    ```

    ## Sample output / expected result
    Example:
Enter your name: Gaurang
Hello, Gaurang!

Enter your name: [press Enter]
Name cannot be empty.
