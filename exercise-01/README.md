# Exercise 01: Git setup

    ## Aim
    Check the Git installation and set the user identity and default branch.

    ## Commands / run instructions
    ```bash
    git --version
git config --global user.name "Gaurang Bhavsar"
git config --global user.email "YOUR_GITHUB_EMAIL"
git config --global init.defaultBranch main
    ```

    ## Sample output / expected result
    Expected checks: Git version is displayed and configured values can be inspected with `git config --global --list`.

    ## Notes
    These files organise the practice shown in the supplied Version Control using Git reference PDF.
