# Exercise 05: Staged and unstaged changes

    ## Aim
    Use `git diff` to inspect edits before and after staging.

    ## Commands / run instructions
    ```bash
    git diff
git diff --staged
    ```

    ## Sample output / expected result
    Expected result: `git diff` shows unstaged changes; after `git add`, `git diff --staged` shows the staged patch.
