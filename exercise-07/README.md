# Exercise 07: Interactive menu

    ## Aim
    Create a menu with greeting, addition, even/odd check, and exit options. Practise a feature branch.

    ## Commands / run instructions
    ```bash
    bash menu.sh
    ```

    ## Sample output / expected result
    Example:
1. Greet
2. Add two integers
3. Check even or odd
4. Exit
Choose an option: 3
Enter integer: 22
Even
