# Exercise 14: Clone and inspect history

    ## Aim
    Clone the team repository and inspect its history.

    ## Commands / run instructions
    ```bash
    git clone https://github.com/OWNER/REPOSITORY.git
git -C REPOSITORY log --oneline
    ```

    ## Sample output / expected result
    Expected result: a local copy is created and its commits can be inspected. Replace the URL and folder name.
