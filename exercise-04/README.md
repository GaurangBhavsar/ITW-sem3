# Exercise 04: Practice files

    ## Aim
    Create two small text files and commit them separately.

    ## Commands / run instructions
    ```bash
    git add file1.txt && git commit -m "Add first practice file"
git add file2.txt && git commit -m "Add second practice file"
    ```

    ## Sample output / expected result
    Expected result: both files are tracked and two descriptive commits appear in `git log`.

    ## Notes
